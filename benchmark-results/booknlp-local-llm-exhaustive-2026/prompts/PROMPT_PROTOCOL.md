# Prompt protocol

The executable prompt builder is `scripts/exhaustive.py` (`call`, `question`, `entity_spans`, `predict_speakers`, and `cluster_coref`). This document records the exact task rules and common wrapper. It does not contain any held-out passage or gold annotation.

## Common token decision wrapper

For each task, the runner takes the tokenized benchmark document and exhaustively creates candidate IDs `0..N-1`. Each request examines exactly one candidate token; enumeration is never delegated to the model. The prompt prints the candidate ID and surface form, with numbered local context (18 tokens on either side on pass 1, 48 on pass 2/3). It asks for a one-element JSON `labels` integer array in order; schema-constrained cardinality equals the number of candidate IDs. The map is task-specific and printed into each request; sparse-label tasks put the negative/none class at index 0 to mitigate class-index bias. Temperature is 0; Ollama thinking is disabled.

Pass 1 and pass 2 are separately prompted, with reversed traversal and wider context in pass 2. Neither sees the other pass's labels. Every disagreement receives a third wider-context independent vote; majority resolves the decision. If all calls for one batch fail JSON/schema validation after three retries, that batch is retained as invalid and receives the task's negative/none fallback, counted in `invalid_batches`.

## Exact task rule text

- **events:** “Label EVENT only when this exact token is a lexical trigger of a specific, asserted realis event in the narrative. Exclude hypothetical, intended, future, counterfactual, generic, negated/non-asserted, and non-event uses. Label each candidate independently.” Index map: `0=NO`, `1=EVENT`.
- **entities:** “Label START if a human or non-human entity mention begins exactly at this token. Include nested and common noun mentions; exclude pronouns. Label each token independently.” Index map: `0=NO`, `1=START`. Positive starts then receive separate shortest-span/type proposals and a yes/no span verification.
- **coref:** “Label START if a referential entity mention (including pronouns and singleton mentions) begins exactly here. Include nested noun phrases. Exclude non-referential, event, and clause spans. Label each candidate independently.” Index map: `0=NO`, `1=START`. Mentions are expanded and typed separately, then linked via pairwise antecedent comparisons and deterministic union-find.
- **quotes:** “Label OPEN for a token beginning direct quoted speech, CLOSE for a token ending direct quoted speech, BOTH if both, and NO otherwise. Include opening/closing delimiters when they are tokenized. Exclude scare quotes, titles, and mentioned terms. Consider punctuation and dialogue dashes; label each candidate independently.” Index map: `0=NO`, `1=OPEN`, `2=CLOSE`, `3=BOTH`. Boundaries are paired mechanically in reading order.
- **supersenses:** “For this exact token, choose its contextual WordNet 3.0 lexicographer supersense if it is a content noun or verb; otherwise NONE. Use one of the listed labels only. Label each candidate independently.” Labels are `NONE` and all 41 benchmark noun/verb supersenses.
- **speaker follow-up:** For each detected quote: “Identify the most likely speaker of the quoted dialogue, using nearby speech tags, actions, conversation turns, and context. If impossible, return null spans/cluster. For a person, speaker span must be a visible mention in these tokens; speaker_cluster must be a stable concise surface-based ID shared across this document. Do not guess the addressee.” Context is ±100 tokens around the predicted quote.
- **coreference follow-up:** Each mention is compared against up to 20 most recent same-type mentions plus all previous exact-surface matches. The prompt asks whether two supplied textual spans “refer to the same underlying entity,” explicitly distinguishing identity from similarity. Two independent phrasings/votes per pair. Edges are unioned deterministically; exact transitivity violations are thereby resolved, but no model adjudication of global cluster contradictions is performed.

The common prefix is: “You perform exhaustive literary annotation. Task={task}. Pass={initial independent judgment | independent adversarial verification}. {task rule} The program has exhaustively enumerated every candidate token ID. Independently decide each listed token. Return a compact JSON integer array named labels in exactly the same order as CANDIDATE IDS, with one label index per ID and no omissions. Do not reveal chain of thought.” The output schema enforces an integer array with exactly one value per supplied candidate.
